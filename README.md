## 🚀 Proyek Unggulan yang Ditonjolkan

1. **Customer Churn Prediction & BI Dashboard (Python / ML / Streamlit)**
   - Dashboard prediktif Machine Learning (Random Forest) untuk memprediksi churn pelanggan telekomunikasi secara real-time dengan visualisasi interaktif Plotly.
2. **TrueCounting Solution - ERP Akuntansi & AI Analyst (PHP / MySQL / Gemini AI / Flutter)**
   - Sistem akuntansi komprehensif terintegrasi Google Gemini AI untuk analisis audit neraca keuangan otomatis, multi-tier RBAC, serta mobile backend API.
3. **Smart Charging & IoT Outlet Rental System (Fintech / PHP / Aiyo Gateway / Google SSO)**
   - Platform penyewaan stop kontak pintar (EV/gadget) dengan live countdown timer, integrasi pembayaran digital otomatis, dan Google Single Sign-On.
4. **CueReserve - Billiard Table Reservation System (Flutter / PHP REST API / MySQL)**
   - Aplikasi mobile multi-platform untuk pengecekan jadwal ketersediaan meja biliar secara real-time.
5. **Superstore Automated ETL Pipeline (Python / Pandas / Cronjob / Batch)**
   - Pipeline otomatis ingestion dan pembersihan dataset transaksi retail berukuran besar (160+ MB) dilengkapi dashboard analitik.
